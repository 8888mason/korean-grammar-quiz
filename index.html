HOW IT WORKS

문맥에서 시작해,
완성문으로 확인합니다.

워크북의 제한형 문법·문맥 완성 문항에서 추가 답안의 적절성을 살피는 과정을 돕습니다.

01

문항의 조건 읽기

원문, 그림, 목표 문법과 모범답안을 함께 확인합니다. 제시된 어휘가 고정된 문항은 그 조건을 유지합니다.

02

필요한 뜻과 관계 조회

어휘 선택이 열려 있거나 의미 관계가 쟁점일 때 우리말샘을 참조합니다. 여러 뜻이 있으면 문맥에 맞는 의미를 명시적으로 확인합니다.

03

선택 이유와 후보 연결

관계에 연결된 양쪽 뜻을 살피고 완성문 후보를 선택합니다. 조회 원응답과 출처, 해당 문항에서 적용할 수 있는 이유를 함께 남깁니다.

04

완성문 검토 후 반영

선택한 후보를 기존 문장 검토 절차로 전달합니다. 목표 문법·문맥·높임·연어 등을 살핀 뒤 승인된 답안을 후속 단계에 반영합니다.

운영 방식 더 알아보기

사전에 연결된 단어는 어떻게 활용하나요?

해당 문항에서 대체할 수 있는지 양쪽 뜻, 그림이 요구하는 정보, 조사·연어와 목표 문법을 함께 살핍니다. 선택한 관계는 후보를 검토할 근거로 남기며 후속 문장 검토를 거칩니다.

조회 결과의 출처는 어떻게 남기나요?

받은 원응답을 보존하고 해당 문항과 원문 해시에 연결합니다. 선택한 의미와 어휘 관계, 후보 완성문, 적용 이유를 함께 기록해 후속 단계에서 근거를 확인할 수 있도록 구성했습니다.

이 사이트에서 무엇을 볼 수 있나요?

프로젝트의 목적, 답안 후보를 살피는 흐름, 로컬 API 활용 방식과 현재 확인 범위를 제공합니다. 실제 문항과 학습자 자료는 운영자의 작업 환경에서 관리합니다.
